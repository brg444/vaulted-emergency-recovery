More detail

What you should have

  • Recovery Kit — map of the vault, plus a locked copy of this phone’s key
  • This page — the steps
  • This phone’s passkey — Face ID, Touch ID, or device PIN
  • Hardware key — required to move ordinary savings
  • Recovery key — only if you chose Advanced

The kit is not a seed. An older map-only file cannot unlock with Face ID if Vaulted is gone.

What you can move

  • Ordinary savings — this phone and hardware, no wait
  • A recovery that already started — wait, then claim with the key that started it
  • Bitcoin still arriving into spending — this phone, after about 90 days
  • Fast spending — not phone-only; after a delay you still need two keys

You cannot start a new waiting period after Vaulted is gone.

What this cannot do

  • Replace a deleted passkey or lost hardware
  • Spend ordinary savings with the phone alone
  • Start a new recovery clock after Vaulted is gone
